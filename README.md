# Alameer Software Firmware (Phicomm K2P)

مشروع Firmware مخصص لجهاز Phicomm K2P (MT7621) مبني على نظام Padavan.

## المواصفات والإعدادات الافتراضية:
- **IP Router:** `192.168.1.20`
- **DHCP Server:** معطل (Disabled)
- **IPv6 / DHCPv6:** معطل (Disabled)
- **WiFi 2.4GHz:** 
  - SSID: `AL-AMEER-NET (   )_2G`
  - Channel: 4, Width: 20, Power: 20dBm
  - No Password (Open)
- **WiFi 5GHz:**
  - SSID: `AL-AMEER-NET (   )_5G`
  - Channel: 116, Width: 40, Power: 23dBm
  - No Password (Open)

## كيفية البناء (Build):
1. اذهب إلى تبويب **Actions** في هذا المستودع.
2. اختر **Build Alameer Firmware (Padavan)**.
3. اضغط على **Run workflow**.
4. بعد اكتمال البناء (حوالي 20-30 دقيقة)، قم بتحميل الملف من قسم **Artifacts**.

## الشعار:
تم استبدال الشعار الافتراضي بشعار **Alameer Software**.
